Вопросы

Частые вопросы

Jeem правда бесплатный?

Да. Ни рекламы, ни подписок, ни платных функций. Код открыт под лицензией MIT.

Windows пишет «Система Windows защитила ваш компьютер». Что делать?

Установщик не подписан платным сертификатом, поэтому SmartScreen его не знает. Нажми «Подробнее» → «Выполнить в любом случае». Весь код открыт на GitHub — его можно проверить.

Откуда берётся музыка?

Jeem ищет и воспроизводит музыку из открытых каталогов YouTube Music, YouTube и SoundCloud. Аккаунт в этих сервисах не нужен.

Где хранятся мои данные?

Только у тебя на компьютере, в папке %LOCALAPPDATA%\com.jeem.app. Если включишь синхронизацию, копия попадёт в скрытую папку приложения на твоём Google Диске — больше никуда.

Как обновлять?

Никак — Jeem сам проверяет обновления и предлагает установить новую версию.

Как удалить Jeem полностью?

«Параметры» → «Приложения» → Jeem → «Удалить». Чтобы убрать и данные, удали папку %LOCALAPPDATA%\com.jeem.app.

Есть версия для Mac или Linux?

Пока только Windows 10 и 11 (64-bit).
